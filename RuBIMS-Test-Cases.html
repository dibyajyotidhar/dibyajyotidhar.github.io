Project Overview

RuBIMS (Rural Bridge Information Management System) is a national-scale web and mobile platform commissioned by the Local Government Engineering Department (LGED) of Bangladesh. The system digitises the cataloguing, condition monitoring, maintenance scheduling, and reporting of rural bridge infrastructure across the country.

As the QA engineer at Eclectic Limited, I was responsible for the full testing lifecycle of the platform — from reviewing functional requirements and writing test plans, to executing test cases, reporting defects, and validating fixes through to final UAT sign-off.

QA Responsibilities

Requirement Analysis

Reviewed BRDs and SRS documents to identify testable requirements, ambiguities, and acceptance criteria gaps before development began.

Test Case Design

Authored detailed test cases covering positive, negative, boundary value, and equivalence partition scenarios for all functional modules.

Test Execution

Executed functional, regression, and exploratory test cycles across multiple sprint releases, tracking pass/fail status with full traceability.

Defect Management

Logged, prioritised, and tracked defects through full lifecycle — discovery → assignment → fix → retest → closure — using project bug tracking tools.

Mobile App Testing

Validated the companion mobile application (Android) for feature parity, offline behaviour, and usability across device form factors.

UAT Coordination

Supported user acceptance testing sessions, preparing UAT test scripts and facilitating sign-off with the client stakeholders.

Testing Approach

01

Requirement Review

Analysed SRS and BRD documents to extract testable requirements. Raised queries for ambiguous acceptance criteria before test design.

02

Test Plan Preparation

Drafted test plan covering scope, approach, entry/exit criteria, risk areas, and resource allocation per module and sprint cycle.

03

Test Case Authoring

Created structured test cases with Test ID, preconditions, steps, expected result, actual result, and pass/fail status columns.

04

Execution & Defect Reporting

Executed cycles, captured evidence (screenshots/videos), and raised defects with reproducible steps, severity, and priority classification.

05

Regression & Retest

Maintained regression suite and performed targeted retests after each bug fix, ensuring no unintended side-effects on existing functionality.

06

UAT & Sign-off

Prepared UAT test scripts, facilitated sessions with LGED stakeholders, documented outcomes, and obtained formal sign-off for each milestone.
